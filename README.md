# MAYA — Version 01

A static first version of the MAYA / Tattva project.

## What is included

- Responsive landing page
- MAYA visual identity and animated orb
- Interactive chatbot with local demo responses
- Tattva / Reality vs Appearance section
- Mobile responsive layout
- Scroll reveal animations
- No backend required

## Run it

The easiest way is to open `index.html` in a browser.

For a local development server:

```bash
python -m http.server 8000
```

Then visit:

http://localhost:8000
