FOR THE ZERO-KNOWLEDGE VIEWER

Think of Tattva as: “What is actually there?”

MAYA explores the difference between appearance and underlying reality. The interface can make an AI feel like a person, while the system underneath is still algorithms, data and models. The project turns that gap into an interactive experience.
